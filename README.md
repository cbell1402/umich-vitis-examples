# umich-vitis-examples

<pre>Currently in use:

_Useful_Python_Stuff_: Stores some misc python scripts used for analyzing, graphing data,
                       and/or organizing data from LDMX-SW to be used to test code in Vitis.
    - These were all run using PyCharm.
    - The data used is taken from an existing ROOT file created using LDMX-SW.
    - The file directories will have to be edited accordingly.

_addition_algos_: Stores the HLS 48 cell addition code. 
    - These can be run directly in the Vitis GUI, with the .cpp file as the source code,
      and the test.cpp, .h, and .txt files in the the testbench.
    - The .txt file can be modified according to the data being tested.

_cluster_algos_: Stores the HLS 2d clustering algorithms.
    - These can be run directly in the Vitis GUI, with the .cpp file as the source code,
      and the test.cpp, .h, and .txt files in the the testbench.
    - The .txt file can be modified according to the data being tested.

_cluster_algos_3d_: Stores the HLS 3d clustering algorithms.
    - These can be run directly in the Vitis GUI, with the .cpp file as the source code,
      and the test.cpp, .h, and .txt files in the the testbench.
    - The .txt file can be modified according to the data being tested.

__

No longer in use:

_cluster_practice_: No longer in use, briefly used to hold example data for testing HLS clustering algorithms.
_stream_addition_: No longer in use, a first attempt at 48 cell addition code in HLS.
_vector_practice_: No longer in use, used briefly for practicing arrays in HLS.
