# Useful_Python_Stuff

<pre>
_neighbor_stuff_: This includes tables and python scripts related to lookup tables
                  for which cells border which other cells in a module.
_new_Particle_Coord_Plot.py_: This creates a 3d graph, using data from a ROOT file made using LDMX-SW,
                              that shows the hit and/or cluster positions.
_writing_to_txt.py_: This is a general use script used to write ROOT data to a txt file for use in Vitis;
                     currently, this lists the trigger cell energies from module 0 in layers 0-31 for one event.
